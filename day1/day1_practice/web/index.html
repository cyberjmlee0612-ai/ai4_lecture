03리스트 · for · %

짝수만 골라내기

다섯 정수를 리스트에 넣고, 2로 나눈 나머지가 0인 값을 찾습니다.

예: -2, 0, 3, 4, 5 · 0과 음수도 입력할 수 있습니다.

입력한 리스트와 짝수가 여기에 표시됩니다.
Python 코드 보기
scores = []
for i in range(5):
    scores.append(int(input("숫자: ")))
for number in scores:
    if number % 2 == 0:
        print(number)

추가 연습: 홀수를 찾거나 합계를 계산해 보세요.

04중첩 for · range

구구단 펼쳐 보기

반복문의 순서를 바꾸면 같은 계산도 다른 방향으로 표시됩니다.

출력 방향을 선택하고 구구단을 실행하세요.
Python 코드 보기
for dan in range(2, 5):
    for i in range(1, 5):
        print(f"{dan} x {i} = {dan * i}", end="\t")
    print()

05난수 · 비교 · 반복

숫자 맞추기 게임

1~100 사이의 정수를 골랐습니다. 크다 / 작다 힌트를 따라 정답을 찾아보세요.

첫 번째 숫자를 입력하세요. 시도 횟수: 0
    Python 코드 보기
    import random
com_number = random.randint(1, 100)
count = 0
while True:
    user_number = int(input("1~100: "))
    count += 1
    if user_number > com_number:
        print("정답보다 큽니다.")
    elif user_number < com_number:
        print("정답보다 작습니다.")
    else:
        print(f"정답! 총 시도 횟수: {count}")
        break
