# EXHIBIT FLOW

전시 프로젝트의 업체·견적 비교, 소통 조건, 준비물과 현장 진행을 한곳에서 관리하는 로컬 웹사이트 시연본입니다.

## 실행

가장 간단한 방법은 `index.html`을 더블클릭하는 것입니다. 로컬 웹 서버로 실행하려면 이 폴더에서 다음 명령을 사용하세요.

```powershell
C:\Users\Playdata\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe -m http.server 5173
```

브라우저에서 `http://localhost:5173`에 접속합니다.

## 현재 구현 범위

- 프로젝트 생성·선택 및 일정/진척 현황
- 업체 견적 추가, 비용·납기·포함 항목 비교, 추천 점수
- 대화 기록 추가, 키워드 기반 요청 사항 초안 생성, 업무 상태 관리
- 준비물/현장 체크리스트 자동 기본 목록, 항목 추가와 완료 처리
- 브라우저 `localStorage` 자동 저장, JSON 백업·복원

샘플 데이터는 화면을 살펴보기 위한 예시입니다. AI 관련 기능은 외부 AI 서비스에 연결되지 않은 규칙 기반 시연 기능이며, 실제 문서 자동 추출·메일 연동·다중 사용자 협업은 포함되어 있지 않습니다.
