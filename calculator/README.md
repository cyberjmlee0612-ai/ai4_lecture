# 두 수 계산기

숫자 두 개를 입력하고 **더하기·빼기·곱하기·나누기** 버튼을 누르면 결과를 보여 주는 학습용 웹 계산기입니다.

## 기술과 동작 방식

- **백엔드: Python + FastAPI** — 입력을 검증하고 실제 계산을 수행합니다.
- **프론트엔드: HTML + CSS** — 숫자 입력 폼, 연산 버튼, 결과를 표시합니다.
- **Jinja2** — 백엔드의 결과를 HTML에 넣습니다. JavaScript 없이 HTML 폼으로 요청합니다.
- **Decimal** — `0.1 + 0.2` 같은 소수 계산을 처리합니다.

```text
브라우저에서 숫자 입력 → 연산 버튼 클릭 → POST /calculate
→ Python에서 입력 검증·계산 → 결과를 포함한 HTML 응답
```

## 파일 구성

calculator/

## 처음 실행하기: Windows PowerShell

Python 3.10 이상이 필요합니다. 다음 명령은 Python이 PATH에 등록되어 있다는 기준입니다. `python`을 찾을 수 없다면 Python을 설치하고 PATH 등록을 선택하거나, 사용 중인 Python 실행 파일의 전체 경로를 사용하세요.

```powershell
cd "C:\ai4_이정민\calculator"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8015
```

검증 과정에서 만들어 둔 `.venv`가 있는 현재 환경에서는 생성·설치를 생략하고 마지막 서버 실행 명령부터 사용할 수 있습니다. 가상환경 활성화 명령을 사용하지 않으므로 PowerShell 실행 정책을 변경할 필요가 없습니다.

- 계산기: <http://127.0.0.1:8015/>
- 자동 API 문서: <http://127.0.0.1:8015/docs>
- 종료: 서버 터미널에서 **Ctrl+C**

기존 환경에서 8000번 포트가 사용 중이어서 8015번으로 검증했습니다. 8015번도 사용 중이면 `--port 8016`으로 변경하고 브라우저 주소의 포트도 바꾸세요.

## 사용 방법

1. 첫 번째 수와 두 번째 수를 입력합니다.
2. 원하는 연산 버튼을 누릅니다.
3. 입력창 아래에서 결과 또는 오류 안내를 확인합니다.

입력값은 계산 후에도 유지됩니다. 숫자나 연산을 바꾸고 다시 계산할 수 있습니다. Enter로 제출할 때는 브라우저의 기본 제출 버튼인 더하기가 선택될 수 있으므로 원하는 연산 버튼을 누르세요.

| 입력 예시 | 연산 | 결과 |
| --- | --- | --- |
| 7, 3 | 더하기 | 10 |
| 7, 3 | 빼기 | 4 |
| -5, 2 | 곱하기 | -10 |
| 7, 2 | 나누기 | 3.5 |
| 0.1, 0.2 | 더하기 | 0.3 |
| 1, 3 | 나누기 | ≈ 0.333333333333 |
| 5, 0 | 나누기 | 오류 안내 |

## 주요 코드 설명

### `parse_number()`

앞뒤 공백을 제거하고 일반적인 십진수 형식인지 검사한 뒤 `Decimal`로 변환합니다. 빈 값, 문자, `NaN`, 무한대, 지수 표기, 쉼표 표기는 거부합니다. `.5`, `-2.5`, `+3`은 허용합니다.

입력 범위는 **-1조부터 1조까지**, 소수점 아래는 최대 **12자리**, 문자열 길이는 최대 **40자**입니다. HTML 제한과 별도로 서버에서도 검증합니다.

### `calculate()`

연산 이름 `add`, `subtract`, `multiply`, `divide`에 따라 계산합니다. 나누기에서는 두 번째 수가 0인지 먼저 확인합니다. 허용 범위 안의 계산에 필요한 정밀도를 확보하도록 `Decimal` 컨텍스트를 60자리로 지정했습니다.

결과는 소수점 아래 최대 **12자리까지 반올림**합니다. 버려지는 값이 정확히 절반이면 0에서 먼 방향으로 반올림하는 `ROUND_HALF_UP`을 사용합니다. 표시값이 계산값과 다르면 `≈`와 안내 문구를 표시합니다. 아주 작은 결과는 `≈ 0`이 될 수 있습니다. 끝의 불필요한 소수점과 0, 음수 0 표기는 정리합니다.

### FastAPI 경로

| 요청 | 역할 | 정상 상태 코드 |
| --- | --- | --- |
| `GET /` | 최초 입력 화면 | 200 |
| `POST /calculate` | 폼 입력 검증 및 계산 화면 반환 | 200 |
| `GET /static/style.css` | CSS 제공 | 200 |

계산 요청의 폼 필드는 `a`, `b`, `operation`입니다. 응답은 JSON이 아니라 HTML입니다. 사용자 입력 오류는 상태 코드 **400**과 함께 같은 화면에 설명을 표시합니다. 빈 입력은 브라우저의 `required` 속성으로 먼저 막으며, 브라우저 검증을 우회해도 서버에서 거부합니다.

템플릿과 CSS 경로는 `main.py` 파일 위치를 기준으로 설정합니다. Jinja2의 HTML 자동 이스케이프를 사용해 입력값을 HTML 코드로 실행하지 않습니다.

## 검증과 재실행

```powershell
cd "C:\ai4_이정민\calculator"
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest -v
```

Python 3.12.14 환경에서 자동 테스트 **6개 모두 통과**했습니다. 각 테스트는 여러 입력 사례를 포함합니다.

- 초기 화면과 CSS 제공
- 사칙연산, 음수, 소수, 0, 허용 범위 경계값
- 결과 반올림 안내와 음수 0 처리
- 0 및 음수 0으로 나누기
- 빈 입력, 문자, 무한대, NaN, 잘못된 연산, 입력 범위·자릿수 초과
- 입력값의 HTML 이스케이프

Python 구문 검사도 통과했습니다. 실제 Uvicorn 서버에서도 초기 화면 200, `0.1 + 0.2 = 0.3` 응답 200, 0으로 나누기 응답 400을 확인했습니다. 브라우저별 실제 화면과 모바일 기기에서의 시각 검증은 수행하지 않았습니다.

테스트에 사용하는 Starlette 버전은 `httpx` 기반 TestClient에 대해 향후 변경 안내 경고를 출력합니다. 현재 고정한 버전 조합에서는 테스트가 정상 통과하며 계산기 실행에는 영향을 주지 않습니다.

## 범위

설치 버전은 검증한 버전으로 고정했습니다. 데이터베이스와 계산 기록 저장은 사용하지 않습니다. `--reload`는 로컬 개발용이며 공개 서비스 운영 설정은 포함하지 않습니다.
