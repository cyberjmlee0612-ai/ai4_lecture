조건에 맞는 값의 개수와 합

def solution(nums):
    count = 0
    total = 0
    for x in nums:
        if x >= 10:
            count += 1
            total += x
    return [count, total]

solution([4, 10, 13])의 결과는 [2, 23]입니다. total과 count는 반복문 밖에서 초기화해야 앞의 결과가 유지됩니다.

def solution(nums):

# 4번 별도로 실행
def solution(n):
    count = 0
    while n > 1:
        n //= 2
        count += 1
    return count
